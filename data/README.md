# Data folder

The dataset is not stored in this repository because of its size.

1. Download **CIC-IDS2017** (`MachineLearningCSV.zip`) from https://www.unb.ca/cic/datasets/ids-2017.html
2. Unzip it and copy `Friday-WorkingHours-Morning.pcap_ISCX.csv` into this folder.
3. Run `python src/train.py --data data/Friday-WorkingHours-Morning.pcap_ISCX.csv` from the project root.
